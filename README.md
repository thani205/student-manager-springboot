# Student Registration System

A web-based Student Registration System developed using Spring Boot, Thymeleaf, and the H2 database.

## Features
- Register new students
- View registered students
- Edit student details
- Delete student records
- Validate student input

## Technologies Used
- Java
- Spring Boot
- Thymeleaf
- H2 Database
- Maven
- HTML and CSS

## How to Run
1. Install JDK 21 and Maven.
2. Clone or download this repository.
3. Open the project in your IDE.
4. Run StudentManagerApplication.java.
5. Open http://localhost:8080/students in your browser.

## Database
The application uses an in-memory H2 database. Data is cleared when the application stops.
